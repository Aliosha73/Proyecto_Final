# Cards4Play

Backend (Java 17 + Spark Java) del Proyecto Final.

## Estructura
- `modelo/`: clases del diagrama (Usuario, Cliente, Administrador, Producto, Carta, Booster, ProductoSellado, Accesorio, InventarioCliente, Torneo, Compra, Rareza, Rol, FuenteTasa, TasaCambio)
- `excepciones/`: ApiException y sus subclases (400, 401, 403, 404, 409)
- `Main.java`: punto de entrada (pendiente: servicios y rutas)

## Pendiente
